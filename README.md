### ⚠️ הודעות אבטחה בעת ההורדה וההתקנה (SmartScreen)
התוסף בטוח לחלוטין לשימוש ואינו כולל שום תוכן מזיק. מכיוון שמדובר בכלי עצמאי חדש ללא תעודת מפתח מסחרית (Code Signing), מערכת ההגנה של Windows והדפדפן עשויים להציג התראת שווא:

* **בהורדה מהדפדפן (Chrome / Edge):** אם מופיעה התראה שהקובץ אינו נפוץ, לחצו על החץ או שלוש הנקודות ובחרו **"השאר בכל זאת" (Keep / Keep anyway)**.
* **בעת הפעלת הקובץ בווינדוס (מסך כחול - Windows SmartScreen):**
  1. במסך שקופץ (*Windows protected your PC* / *הגנת Windows על המחשב שלך*), לחצו על הקישור **"מידע נוסף" (More info)**.
  2. לחצו על הכפתור שנוסף למטה: **"הפעל בכל מקרה" (Run anyway)**.
